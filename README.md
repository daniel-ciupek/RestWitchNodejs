# Random Quotes App

Prosta aplikacja wyświetlająca losowe cytaty. Backend działa w Node.js, frontend w HTML/CSS/JS.

## Jak uruchomić lokalnie

1. Sklonuj repozytorium i przejdź do folderu projektu:

```
git clone https://github.com/<TwojeRepo>/RestWitchNodejs.git
cd RestWitchNodejs
```

2. Zainstaluj zależności:

```
npm install
```

3. Uruchom serwer:

```
npm start
```

4. Otwórz przeglądarkę i przejdź do:

```
http://localhost:8080
```
